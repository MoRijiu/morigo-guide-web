# MoriGo 导航站 · 需求文档

> 版本：v1.1.0 起维护。产品定位、功能边界与迭代路线以本文为准；视觉规范见 `docs/DESIGN.md`。

## 1. 产品定位

MoriGo 是一个开源、可自部署的网址导航站：打开就能用，核心价值是**快**——打开快、找得快、点开快。纯静态构建，产物可发布到任意静态托管。仓库默认数据只含通用示例分类；任何部署者（含维护者本人）的私人站点清单走 gitignored 的 `src/config/navigation.local.ts` 本地覆盖，构建时合并置顶，不进仓库。

设计原则：

- **紧凑优先**：信息密度高、留白克制，拒绝大横幅、大按钮、大间距。
- **零等待**：纯静态站，无后端依赖；搜索、过滤全部本地完成，输入即出结果。
- **本地优先**：收藏、最近访问、主题偏好存 localStorage，不上传、不追踪。
- **深色友好**：浅色/深色双主题，跟随系统并可手动切换。

## 2. 功能需求

### 2.1 已有（v1.0.0）

- 分类导航卡片（图标 + 标题 + 一句话描述），数据内置于 `src/config/navigation.ts`。
- 站内搜索：按标题/描述/URL 实时过滤。
- 外部引擎切换：站内 / 百度 / 必应 / Google。
- 暗色模式切换并持久化；回到顶部；响应式布局。

### 2.3 非目标

- 不做账号系统、不做服务端云同步（跨设备靠 R50 手动同步码，数据不经服务器）。
- 不做服务端编辑后台；访客的自定义站点只存本机浏览器（R10），默认数据仍改代码走 PR。
- 不接统计/追踪脚本。

## 3. 环境与发布

MoriGo 是纯静态站点：`npm run build` 的产物在 `dist/`，发布到任意静态托管服务或 Web 服务器即可（官方演示站见 README 的在线预览链接）。

| 环境 | 构建方式 | 说明 |
| --- | --- | --- |
| 生产 | `npm run build` | 版本徽标为裸版本号 |
| 测试 | `VITE_APP_ENV=test npm run build` | 版本徽标加 `_test` 后缀 |
| 开发 | `npm run dev` | `VITE_APP_ENV` 未设时徽标显示 `_dev` |

版本徽标：版本号取 `package.json` 的 `version`（构建时注入），按环境加后缀——测试 `_test`、生产裸版本号、开发 `_dev`。

## 4. 数据维护

导航数据在 `src/config/navigation.ts`，结构见 `src/types/index.ts`（分类 → 条目：标题/描述/URL/Iconify 图标名）。新增条目要求：标题准确、描述一句话 ≤ 16 字、图标优先用 Iconify 已有图标、URL 用 HTTPS 正式地址；同时补 `nameEn` / `nameJa`（分类）与 `descriptionEn` / `descriptionJa`（条目）字段（R26 起的多语口径，缺省按 英→中 / 日→英→中 回退，目标语言模式下露出回退文案即视为待补）。
