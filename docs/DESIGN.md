# MoriGo 导航站 · 设计规范

> 与 `docs/REQUIREMENTS.md` 配套。核心审美取向：**紧凑、现代、克制**——避免大留白、大按钮、松散排版。

## 1. 布局

- 内容最大宽度 `max-w-6xl`（72rem），两侧内边距移动端 20px / 桌面 32px。
- 顶栏高度 56px（`h-14`），sticky + 毛玻璃背景。
- 首屏结构：顶栏 → 标题区（标题 24–30px、标语 12px、搜索框）→ 分类卡片流 → 页脚。标题区上下留白 ≤ 48px，不做 hero 大横幅。
- 卡片网格：移动端 2 列、平板 3 列、桌面 4 列，间距 12px。

## 2. 色彩

- 基础色板：Tailwind `surface`（中性灰阶）打底，`accent` 为唯一强调色。
- 卡片：白底（深色为 surface-900）、1px 细边框、圆角 10px；禁止彩色阴影、渐变胶囊堆叠。
- 图标：统一线性/品牌图标（Iconify），尺寸 20–24px，置于浅灰底圆角方块中（R4 起按品牌色着色底）。
- 深色模式与浅色模式成对设计，任何新组件必须同时验两套。

## 3. 字体与字号

- 字体：Inter（正文）+ Space Grotesk（标题/Logo）。
- 正文字号 12–14px 为主：卡片标题 14px、描述 12px、页脚 11px。禁止正文超过 16px 的「宣传式」排版。

## 4. 组件口径

- 按钮/可点元素：小尺寸优先（图标按钮 32×32px，圆角 6–8px），hover 只变底色/文字色，不放大不位移（Logo 箭头等微动效除外，位移 ≤ 2px）。
- 搜索框：单行、高度 ≤ 44px，引擎切换用分段小标签，不用下拉大菜单。
- 空状态：一句文案 + 一个可执行动作（如「用百度搜索」），不放插图占位。
- 动效：渐入/过渡 150–250ms，`ease-out`；尊重 `prefers-reduced-motion`（R5 落地）。

## 5. 双语与按钮口径（R26 补）

- 英文文案普遍比中文长 1.5–2 倍：工具栏/面板按钮一律 `shrink-0` + 单行优先，文案先想英文长度再定稿；放不下先缩短英文文案，其次加宽面板，不许靠折行硬塞。
- 弹层面板层级统一 z-50，必须盖过 sticky 分类条（z-40）；新增面板照此办（导入导出面板曾因 z-40 被分类条腰斩）。
- 固定宽度列（如统计面板分类名列）按英文最长名留宽并加 `title` 兜底截断。
- 每轮涉及文案/数据改动时，en 模式下扫一遍可见文本：默认数据与 UI 不应露出未翻译中文（品牌专名除外）。

## 5.1 移动端弹层口径（R28 补）

- 工具栏按钮会随宽度换行，**禁止把固定宽面板只用 `right-0` 锚到单个按钮**：按钮不在行尾时面板会切出屏幕。工具栏面板在 `max-sm` 下一律底部抽屉式：`fixed` 贴底、左右 12px、限高 78dvh + `overflow-y-auto` 内部滚动；桌面（sm+）保持锚点下拉原样。
- 一切弹层必须限高 + 内部滚动（面板 85dvh、抽屉 78dvh、下拉 55dvh、Modal 85–92dvh，统一用 dvh 单位），不许靠页面滚动够到被截断的下半截。
- 整宽底部抽屉型 Modal（贴边、圆角只在顶部）是既定形态，不按「留边距」口径判溢出；但同样必须限高 + 内部滚动。
- 新增弹层后按 320/360/375/390 四档宽度逐个打开量一遍 rect：左右不越界（抽屉型除外）、底部不被截、内容滚动在弹层内部。
- **弹层关闭口径（R34 补）**：一切弹层统一三种关闭方式——触发按钮开关、点面板外关闭、Esc 关闭，缺一不可（导入/导出面板曾只有按钮开关，移动端抽屉弹出后点外面关不掉）；实现用根元素包含判定 + document pointerdown/keydown 监听，触发按钮与面板同属一个根元素，避免一开就关、关了又开。
- **状态呈现口径（R34 补）**：切换类按钮必须直接呈现当前状态，不许只显示「将要切换到的目标」——语言切换即为此例：用「中文 | EN」双段式、当前语言高亮，点任意一段直接切到该语言。

## 6. 版本徽标

- 位置：页脚右侧，域名链接之前，11px 灰色文字，格式 `v<version>`；测试环境 `v<version>_test`、开发 `v<version>_dev`、生产裸版本号。
- 版本号来源：构建时从 `package.json` 注入（`__APP_VERSION__`），禁止手写。

## 7. 自查清单（每轮部署后）

- 桌面（1280px）与移动（390px）各截一图：无横向溢出、无错位、暗色模式正常。
- 搜索空结果、长标题、长 URL 三种边界数据下卡片不破版。
- 线上 bundle 哈希与本地构建一致，页面标题正确。
